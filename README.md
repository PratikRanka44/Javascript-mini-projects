# JavaScript Mini Projects

A collection of JavaScript mini-projects built with HTML, CSS, and Vanilla JavaScript (ES6+). These projects are designed for learning, experimentation, and practice.

##  Technologies Used
- **Core Technology**: JavaScript (ES6+)
- **Styling**: HTML, CSS (usable with frameworks like Bootstrap or Tailwind CSS)
- **Version Control**: Git + GitHub

##  Project Structure

| Folder / File             | Description                                              |
|---------------------------|----------------------------------------------------------|
| `css/`                    | CSS stylesheets or framework files                       |
| `images/`                 | Assets such as images used in the projects               |
| `js/`                     | JavaScript files, if separated from HTML                 |
| `index.html`              | Project landing page showcasing all the mini-projects    |
| `Notes.html`              | Personal notes or documentation related to development   |
| `QR.html`                 | A mini-project for generating/displaying QR codes        |
| `Quizz App.html`          | A JavaScript-based Quiz application                      |
| `ToDoList.html`           | A simple To-Do List app using JavaScript                 |
| `age_calculator.html`     | Age Calculator project in JavaScript                     |
| `music.html`              | Mini Music Player or interface demo                      |
| `random password.html`    | Random Password Generator project                        |
| `weather.html`            | Weather App using an API (e.g., OpenWeatherMap)          |
